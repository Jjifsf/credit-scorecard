# 信用评分卡建模项目（Give Me Some Credit）

## 1. 项目背景
信贷风控中，信用评分卡是一种可解释性强的模型，用于评估客户的违约风险。本项目基于Kaggle公开数据集`Give Me Some Credit`，从原始数据开始，独立完成数据清洗、特征工程、逻辑回归建模、模型评估及可解释评分卡生成。

## 2. 数据来源
- 训练集：`cs-training.csv`（15万条样本，11列，含违约标签）
- 目标变量：`SeriousDlqin2yrs`（1=违约，0=正常）
- 特征：10个（年龄、负债比率、月收入、逾期次数、信贷账户数等）

## 3. 数据处理与清洗
- 缺失值处理：
  - `MonthlyIncome`：用中位数填充
  - `NumberOfDependents`：用0填充（无家属）
- 异常值截断（基于99%分位数或业务阈值）：
  - 年龄：限制在18~100岁，超出用中位数替换
  - 信用卡额度使用率：限制在[0,1]
  - 负债比率：限制在[0,1]
  - 逾期次数、账户数、房产贷款数：截断至99%分位数

## 4. 特征工程（分箱 + WOE/IV）
- 使用`scorecardpy`决策树分箱（最多5箱）
- 计算每个变量的IV值（信息量）：
  - 额度使用率 (1.08)、逾期90天次数 (0.84)、逾期30-59天次数 (0.74) 等为强预测因子
- **手动调整**：因负债比率最后一箱违约率不单调，合并尾部两箱，确保评分卡业务可解释性

## 5. 建模与验证
- WOE转换后，将训练集分割为训练集（70%）和验证集（30%）
- 逻辑回归（无正则化）模型，系数全为正，符合业务直觉
- 验证集性能：
  - AUC = 0.8552
  - KS = 0.5597
  （说明模型区分好坏客户能力优秀）

## 6. 生成评分卡
- 基础分：576
- 每个变量各分箱对应整数分数（正分表示风险降低，负分表示风险增加）
- 最终分数范围：235 ~ 768
- 好客户平均分636.7，坏客户平均分497.5，分离明显

### 评分卡示例（部分）
| 变量 | 分箱区间 | 分数 |
|------|----------|------|
| RevolvingUtilizationOfUnsecuredLines | [-inf,0.14) | +58 |
| ... | [0.86,inf) | -60 |

（完整评分卡见附件 `scorecard.xlsx`）

## 7. 结论
本项目独立完成了端到端的信用评分卡建模，模型区分能力优秀（AUC>0.85），评分卡单调且可解释，可直接用于风险评估场景。
